# Licensing and attribution

This directory collects existing research scripts and source packages.
Collection does not change their authorship, copyright, or license.

- Each source package retains its original `DESCRIPTION` and license files.
- HMP and miLineage are third-party packages, not new MetaQCAT implementations.
- No blanket new license is assigned to analysis scripts that did not already
  carry an explicit license. Consult the authors before redistributing such
  scripts under a different license.

See `docs/THIRD_PARTY.md` for the bundled package inventory and licensing.
